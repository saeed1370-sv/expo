Homogeneous model: total mass flow W [kg/h], mixture density ρmix [kg/m³], ΔP [bar]. Kd, Kw, Kc are entered separately; Ceff = Kd × Kw × Kc is calculated automatically.
Required effective orifice area (Areq):

Automatic API 526 orifice selection:
Orifice Letter: ---
AAPI = --- cm² (≈ --- in²)
First, Q = W / ρmix (W in kg/s, Q in m³/s), then the same incompressible orifice equation as for liquid is applied. For rigorous two-phase sizing (flashing, non-equilibrium) refer to detailed API / ISO methods and process simulation tools.
